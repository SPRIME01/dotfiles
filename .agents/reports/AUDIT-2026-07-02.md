# Adversarial Audit — 2026-07-02

Goal tested: "clone on a blank machine, run one command, get a working environment."
Verdict: **fails today.** Two provisioning-breaking bugs, one identity crisis, and ~40% of the repo is dead weight.

## P0 — Breaks provisioning on a new machine

1. **`bootstrap.sh:24` symlinks `$DOTFILES/.bashrc` → file does not exist.**
   Only `dot_bashrc.tmpl` (chezmoi) exists. Fresh machine gets a dangling `~/.bashrc` symlink; bash starts with nothing. Same risk for every `ln -sf` target — none are verified before linking. Fix: either generate `.bashrc` or delete the symlink block and let chezmoi own it.

2. **Two competing provisioning systems with no owner.**
   README says `./bootstrap.sh` (symlink model). `docs/tutorials/new-machine-setup.md` says `bash install.sh` (chezmoi model, `dot_*.tmpl`). They manage the *same files* (`.zshrc` vs `dot_zshrc.tmpl`, `justfile` vs `dot_justfile`) and will drift/fight. Pick one (chezmoi is further along), delete the other, fix the README.

3. **Live runtime state lives inside the git working tree.**
   `~/.zshrc.safe.d` symlinks into the repo, so zsh writes `.zcompdump*`, `.zwc`, and `.zsh_history` into the checkout. Five `.zcompdump*` binaries are *tracked*; the repo is permanently dirty (24 modified files at session start) and `git pull`/`chezmoi apply` on any machine can conflict on machine-local caches. Fix: `git rm --cached .zshrc.safe.d/.zcompdump*`, add `**/.zcompdump*`, `*.zwc`, `.zsh_history` to `.gitignore`, point ZDOTDIR at a real `~/.zshrc.safe.d` dir that only *sources* from the repo.

## P1 — Security

1. **`.zshrc.safe.d/.zsh_history` sits in the repo dir (untracked).** One careless `git add -A` publishes your shell history. Covered by fix #3.
2. **`.secrets.json` is tracked but SOPS/age-encrypted — OK** as designed. Residual risk: nothing stops a plaintext edit being committed. Add a pre-commit check that the file contains `ENC[` (there's already `scripts/git-hooks/pre-commit` to extend). Note: git hooks aren't installed automatically on a new machine — bootstrap should `git config core.hooksPath scripts/git-hooks`.
3. **`curl | sh` without verification**: `scripts/install-tailscale.sh:18`, `scripts/setup-wsl2-remote-access.sh:205`, `install_complete.sh:54` (oh-my-posh), `install.sh:50/60`. You already built `lib/secure-install.sh` with checksum verification — these scripts just don't use it. Route them through it or use the distro package (`apt install tailscale` via tailscale's repo).
4. **Dependabot automerge workflow** (`.github/workflows/dependabot-automerge.yml`) auto-merges into a repo that machines blindly execute on provision. Require at least CI green + no major bumps.
